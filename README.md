# Le Donjon des Mots

An Undertale-inspired game that helps a 10-year-old practise French: where they live, weather, and numbers.

The whole game is `index.html`, a single static page that GitHub Pages can serve as is.

Play it at https://racheljeffreyrochelle-prog.github.io/Le-Donjon-des-Mots/ (introduction page: https://racheljeffreyrochelle-prog.github.io/Le-Donjon-des-Mots/intro/)

The product requirements for the first release are in [PRD.md](PRD.md).

What I built at Hack Day Manchester on 28 October 2026 is summarised at https://racheljeffreyrochelle-prog.github.io/Le-Donjon-des-Mots/hackday/ (source in [hackday/index.html](hackday/index.html)).
